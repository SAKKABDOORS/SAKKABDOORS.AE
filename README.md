# SAKKAB Doors — موقع سكاب للأبواب

متجر إلكتروني كامل لمجموعة سكاب (WPC، UPVC، ألمنيوم)، مبني بـ **Next.js 14 (App Router) + TypeScript + Tailwind CSS + Prisma**، بديزاين مأخوذ من الكاتالوج الرسمي (PDF) يلي زودتونا فيه.

## المزايا المنفذة

- **ديزاين مطابق للكاتالوج الرسمي**: هيرو بخلفية صورة + Overlay غامق، شريط إحصائيات (خبرة/مشاريع/عملاء) بعداد متحرك، شبكة خدمات (ألمنيوم/أبواب/عقارات/WPC)، 3 أقسام "spotlight" لكل خط منتجات (WPC، UPVC، ألمنيوم) بنفس نصوص الكاتالوج، قسم الثقة (جودة/ضمان/ابتكار)، بانر دعوة لإجراء، وفوتر فيه فروعكم الثلاثة الحقيقية (أبوظبي، العين، دمشق-صحنايا) بأرقام الهاتف والإيميل.
- **معرض/كتالوج منتجات مع فلترة** حسب الفئة (WPC/UPVC/ألمنيوم) والسعر.
- **دعم لغتين (عربي/إنجليزي)** مع تبديل تلقائي لاتجاه الصفحة RTL/LTR.
- **لوحة تحكم للإدارة** محمية بتسجيل دخول: إضافة/تعديل/حذف منتجات، عرض الطلبات، وإدارة المساعد الذكي.
- **تواصل مباشر**: زر واتساب عائم + فورم طلب/تواصل بكل صفحة منتج وصفحة التواصل.
- **إرسال الطلب تلقائياً بالإيميل** إلى `FAX@SAKKABDOORS.AE` فور تعبئة أي فورم طلب، مع حفظ كل طلب بقاعدة البيانات حتى لو فشل الإيميل.
- **أنيميشن بـ Framer Motion**: دخول متدرّج، عداد أرقام متحرك، ظهور تدريجي أثناء التمرير، انتقال ناعم بين الصفحات.
- **مساعد ذكاء اصطناعي (اختياري)**: زر عائم بالموقع يجاوب زوار الموقع، ومساحة "تدريب" بلوحة التحكم (`/admin/ai`) يضيف منها الأدمن معلومات (أسئلة شائعة، سياسات، تفاصيل منتجات) — المساعد بيجاوب فقط من هاي المعلومات + كتالوج المنتجات الحالي، ما بيختلق معلومات.

## ⚠️ ملاحظة عن الديزاين

بنيت الديزاين اعتماداً على ملف الـ PDF يلي بعتّوه (الهيرو، شريط الإحصائيات، شبكة الخدمات، أقسام WPC/UPVC/Aluminum، قسم الثقة، البانر، والفوتر) — لكن بالكاتالوج شفت "CART" بالقائمة العلوية و"SHOP NOW" كزر. حالياً الموقع شغال بنظام **"اطلب عرض سعر" (Request a Quote)** مش سلة شراء ودفع أونلاين فعلي (زي ما حددتوا بأول محادثة). إذا بدكم فعلياً سلة شراء حقيقية مع Checkout ودفع أونلاين، خبروني لنضيفها كمرحلة تانية — هاد قرار بيأثر على الهيكلية شوي فحبيت أوضحه قبل ما نبني عليه.

كمان: الصور المستخدمة حالياً (الهيرو، صور الفئات، صور المنتجات) صور Unsplash placeholder فقط — استبدلوها بصوركم الحقيقية من موقع Canva أو من تصويركم الخاص قبل ما تنزلوا الموقع بالإنتاج (الأماكن يلي لازم تستبدلوا فيها الصور موضحة بالتعليقات جوا الكود: `components/Hero.tsx`، `prisma/seed.ts`).

## ⚠️ ملاحظة مهمة عن هذه الجلسة

بيئة العمل يلي جهزت فيها هاد الكود ما إلها وصول لإنترنت/npm registry، فما قدرت أشغّل `npm install` ولا أختبر السيرفر فعلياً هون. كل الملفات مكتوبة يدوياً باتباع نمط Next.js الصحيح، وتم فحصها ببرنامج تحقق نحوي (`scripts/syntax-check.mjs`) وطلعت كلها سليمة (58 ملف) — بس لازم تشغّل الخطوات تحت عندك أو على سيرفر عنده إنترنت قبل ما تشتغل عليه فعلياً.

## التشغيل المحلي

```bash
npm install
cp .env.example .env
# عدّل DATABASE_URL, ADMIN_SESSION_SECRET, بيانات SMTP، AI_PROVIDER (اختياري)

npx prisma db push      # يبني الجداول على قاعدة MySQL يلي حطيتها بـ DATABASE_URL
npm run db:seed         # بيانات تجريبية + مستخدم أدمن (اسم المستخدم admin، وكلمة سر عشوائية قوية بتطبع مرة وحدة بالـ terminal — احفظها فوراً وغيّرها من /admin)
npm run dev             # http://localhost:3000 → يحوّلك تلقائياً لـ /ar
```

لوحة التحكم: `http://localhost:3000/admin/login`

> ما عندك MySQL محلياً؟ أسهل حل: نزّل MySQL/MariaDB محلياً أو شغّله بـ Docker (`docker run -e MYSQL_ROOT_PASSWORD=pass -p 3306:3306 mysql:8`)، أو مؤقتاً بدّل `provider = "mysql"` بـ `prisma/schema.prisma` إلى `"sqlite"` و `DATABASE_URL="file:./dev.db"` بـ `.env` للتجربة السريعة بدون سيرفر قاعدة بيانات.

## النشر على cPanel (دومين إماراتي)

معظم استضافات cPanel الحديثة فيها **Setup Node.js App** (مبني على Phusion Passenger) و**MySQL Databases** — هيك الخطوات:

1. **قاعدة البيانات**: من cPanel → MySQL® Databases، أنشئ قاعدة بيانات ومستخدم واعطيه كل الصلاحيات عليها. لاحظ إنو cPanel بيضيف بادئة اسم المستخدم تلقائياً (مثلاً `cpaneluser_sakkab`). استخدم هاي البيانات بـ `DATABASE_URL` بصيغة:
   `mysql://DB_USER:DB_PASSWORD@localhost:3306/DB_NAME`

2. **رفع الكود**: ارفع محتويات المشروع (بدون `node_modules` و`.next`) لمجلد التطبيق عن طريق File Manager أو Git، أو SSH إذا متوفر.

3. **Setup Node.js App**: من cPanel:
   - Node.js version: اختر أحدث نسخة LTS متوفرة (18 أو 20)
   - Application root: مجلد المشروع
   - Application URL: الدومين أو الساب-دومين
   - **Application startup file: `server.js`** ← هاد مهم، لأنو Passenger بده ملف يشغّل السيرفر (مو `next start` مباشرة)
   - بعد الإنشاء، من نفس الصفحة أضف كل متغيرات `.env` (Environment Variables) — أو ارفع ملف `.env` مباشرة لمجلد التطبيق

4. من صفحة Node.js App، افتح **Terminal** (أو زر "Run NPM Install") وشغّل بالترتيب:
   ```bash
   npm install
   npx prisma db push
   npm run db:seed
   npm run build
   ```

5. اضغط **Restart** من صفحة Node.js App. الموقع لازم يشتغل على الدومين مباشرة.

6. **ربط الدومين**: إذا الدومين الإماراتي (.ae) مسجل بمزود تاني، وجّه الـ Nameservers أو الـ A Record لسيرفر الاستضافة، وتأكد إنو "Application URL" بإعدادات Node.js App مطابق للدومين.

7. **SSL**: فعّل AutoSSL (Let's Encrypt) من cPanel منشان HTTPS — لازم يكون شغال قبل ما تفعّل كوكي الأدمن بوضع "secure" بالإنتاج (already handled — `NODE_ENV=production` بيفعّلها تلقائياً).

## الذكاء الاصطناعي — كيف "تدرّبوه"

المساعد الذكي (الزر بأسفل الموقع، جنب زر الواتساب) **مو نموذج مدرّب من الصفر ولا Fine-tuned** — هو استدعاء لنموذج جاهز (Claude أو GPT) بس بنعطيه "سياق" محدد قبل كل سؤال، مبني من:

1. حقائق ثابتة عن الشركة (الفروع، أرقام التواصل) — مكتوبة بـ `lib/ai.ts`.
2. **قاعدة المعرفة** يلي تديروها من `/admin/ai` — أضف/عدّل/احذف معلومات (أسئلة شائعة، سياسات، شرح فرق بين WPC/UPVC/ألمنيوم، إلخ). هاد هو "التدريب" الفعلي — كل ما تضيف معلومة جديدة هون، المساعد بيصير يعرفها فوراً بدون أي إعادة نشر أو تدريب.
3. كتالوج المنتجات الحالي (يتحدث تلقائياً من قاعدة البيانات).

المساعد ممنوع يختلق معلومات مو موجودة بهاي المصادر الثلاثة — لو ما يعرف الجواب، بيوجّه الزائر للواتساب.

بصفحة `/admin/ai` كمان بتشوف **آخر الأسئلة الحقيقية** يلي الزوار سألوها — استخدمها لتعرف وين في نقص بالمعلومات وضيف معلومة جديدة تسدها.

**للتفعيل**: بملف `.env` غيّر:
```
AI_PROVIDER="anthropic"        # أو "openai"
ANTHROPIC_API_KEY="sk-ant-..."  # من console.anthropic.com
NEXT_PUBLIC_AI_CHAT_ENABLED="true"
```
قبل التفعيل، الزر بيضل ظاهر بس بيوجّه أي سؤال لرسالة "غير مفعّل بعد + تواصل عبر واتساب" — هيك جاهز التصميم من الآن وبس تحطوا المفتاح لما تكونوا جاهزين.

## قبل الإنتاج — قائمة تحقق سريعة

1. أول ما تشغّل `npm run db:seed`، بتطبع كلمة سر عشوائية قوية لمرة وحدة بالـ terminal — احفظها فوراً، وغيّرها من `/admin` بعد أول دخول (ممكن كمان تحدد يوزر/باسورد خاص فيك مسبقاً عبر `DEFAULT_ADMIN_USERNAME`/`DEFAULT_ADMIN_PASSWORD` بملف `.env`).
2. ولّد `ADMIN_SESSION_SECRET` عشوائي: `openssl rand -hex 32`.
3. اربط SMTP حقيقي (بريد الدومين sakkabdoors.ae أو SendGrid/Mailgun) بحيث تصل الطلبات فعلياً لـ `FAX@SAKKABDOORS.AE`.
4. استبدل كل صور Unsplash التجريبية بصوركم الحقيقية (`components/Hero.tsx`، `prisma/seed.ts`).
5. فعّل الذكاء الاصطناعي وجرّب كذا سؤال، وأضف معلومات كافية بـ `/admin/ai` قبل ما تعتمدوا عليه بالكامل.
6. راجع رقم الواتساب والأرقام بالفوتر (`NEXT_PUBLIC_WHATSAPP_NUMBER`, `components/Footer.tsx`).

## نقاط توسّع مقترحة لاحقاً

- صفحة "تغيير كلمة مرور الأدمن" ومستخدمين أدمن متعددين بصلاحيات مختلفة.
- Streaming responses للمساعد الذكي (حالياً الرد بيوصل دفعة وحدة، مو Streaming).
