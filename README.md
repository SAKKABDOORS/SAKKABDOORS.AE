# SAKKAB Doors — موقع سكاب للأبواب

متجر إلكتروني كامل لمجموعة سكاب (WPC، UPVC، ألمنيوم) + قسم عقارات ووظائف، مبني بـ **Next.js 14 (App Router) + TypeScript + Tailwind CSS + Prisma**.

## المزايا المنفذة

- **ديزاين مخصص** مبني على هوية سكاب البصرية (أخضر/رملي)، بأزرار دائرية، خط عناوين مميز، وحركات سينمائية خفيفة.
- **معرض/كتالوج منتجات** مع فلترة حسب الفئة والخامة والسعر، وصفحة مخصصة لكل فئة (WPC/UPVC/ألمنيوم).
- **قسم عقارات** (`/realestate`) بفلترة حسب المنطقة والسعر، مع أزرار اتصال/واتساب مباشرة على كل بطاقة.
- **قسم الوظائف الشاغرة** (`/careers`) بنظام تقديم مدمج بنفس نظام الطلبات.
- **دعم لغتين (عربي/إنجليزي)** مع تبديل تلقائي لاتجاه الصفحة RTL/LTR.
- **لوحة تحكم للإدارة** بثلاث صلاحيات (مسؤول/مدير/موظف)، محمية بتسجيل دخول: إضافة/تعديل/حذف منتجات وعقارات ووظائف، عرض الطلبات، إدارة محتوى الموقع، وإدارة المساعد الذكي.
- **تواصل مباشر**: زر واتساب عائم + فورم طلب/تواصل بكل صفحة منتج/عقار وصفحة التواصل.
- **إرسال الطلب تلقائياً بالإيميل** فور تعبئة أي فورم طلب، مع حفظ كل طلب بقاعدة البيانات حتى لو فشل الإيميل.
- **تصدير كتالوج PDF** من لوحة التحكم.
- **SEO**: `robots.txt`، `sitemap.xml` ديناميكي، عناوين ووصف مخصصة لكل صفحة، Open Graph، hreflang، وبيانات Organization المهيكلة (JSON-LD).
- **مساعد ذكاء اصطناعي (اختياري)**: زر عائم بالموقع يجاوب زوار الموقع من قاعدة معرفة يديرها الأدمن + كتالوج المنتجات الحالي.

## البنية التقنية

| الطبقة | التقنية |
|---|---|
| Framework | Next.js 14 (App Router, Server Components) |
| اللغة | TypeScript |
| التنسيق | Tailwind CSS |
| الأنيميشن | Framer Motion |
| قاعدة البيانات | Prisma ORM — MySQL/MariaDB |
| المصادقة (الإدارة) | جلسة موقّعة بـ JWT (jose) + كوكي httpOnly، كلمات مرور مشفّرة bcrypt |
| الإيميل | Nodemailer عبر SMTP |
| الاستضافة | Vercel |

## هيكل المشروع

```
app/
  (storefront)/[locale]/    الموقع العام (رئيسية، كتالوج، عقارات، وظائف، من نحن، تواصل) — ثنائي اللغة
  (admin-app)/admin/        لوحة التحكم (محمية بتسجيل دخول + صلاحيات)
  api/                      كل الـ API routes
  robots.ts, sitemap.ts     ملفات SEO
components/                 مكونات الواجهة (عامة + لوحة الإدارة)
lib/                        منطق مشترك (i18n، auth، أدوار الإدارة، mailer، prisma...)
prisma/
  schema.prisma             نموذج قاعدة البيانات (MySQL)
  seed.ts                   بيانات تجريبية (فئات + منتجات + قاعدة معرفة + أدمن)
```

## التشغيل المحلي

```bash
npm install
cp .env.example .env
# عدّل DATABASE_URL, ADMIN_SESSION_SECRET, بيانات SMTP

npx prisma db push
npm run db:seed         # بيانات تجريبية + مستخدم أدمن (اسم المستخدم admin)
npm run dev             # http://localhost:3000
```

لوحة التحكم: `http://localhost:3000/admin/login`

## النشر — Vercel

الموقع منشور عبر **Vercel** (وليس عبر الاستضافة المحلية cPanel، التي لا تدعم تشغيل تطبيقات Node.js):

1. اربط المستودع بحساب Vercel (أو استخدم `vercel` CLI).
2. أضف كل متغيرات البيئة من `.env.example` في إعدادات المشروع على Vercel (Environment Variables).
3. تأكد إن `DATABASE_URL` يشاور على قاعدة MySQL يمكن الوصول إليها من الإنترنت (وليس قاعدة محلية).
4. اربط الدومين `sakkabdoors.ae` من إعدادات Domains بمشروع Vercel، وحدّث الـ DNS عند مزود الدومين ليشاور على Vercel.
5. الإيميل (SMTP) والدومين يضلوا يعملوا بشكل مستقل تماماً عبر استضافة cPanel الحالية — فقط الموقع نفسه انتقل لـ Vercel.

## قبل الإنتاج — قائمة تحقق سريعة

1. ولّد `ADMIN_SESSION_SECRET` عشوائي وحقيقي (وليس القيمة الافتراضية).
2. تأكد إن حساب الأدمن الافتراضي غيّر كلمة مروره من `/admin` بعد أول دخول.
3. تأكد من `DATABASE_URL` يشاور على قاعدة بيانات إنتاج حقيقية (مو placeholder).
4. راجع رقم الواتساب والأرقام بالفوتر (`NEXT_PUBLIC_WHATSAPP_NUMBER`).
5. فعّل الذكاء الاصطناعي (اختياري) وجرّب كذا سؤال قبل الاعتماد عليه بالكامل.
